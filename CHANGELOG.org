* Changelog

** 0.2.0 - 

Complete rewrite of the code. Added more sources and parsing additional sections depending on the source. 

- =CHANGED= Lemma normalization now first checks DWDS snippets for direct matches and falls back to DWDS frequency lookup only when needed.
- =CHANGED= Multi-word expressions are no longer lemma-normalized.
- =FIXED= Multi-word URL paths are now built correctly for Duden and Wiktionary.
- =ADDED= DWDS: idioms, origin
- =ADDED= Wiktionary: definitions, idioms, origin, examples
- =ADDED= Duden as source: definitions, idioms, origin, example, synonyms
- =FIXED= Duden-Synonyme werden bei qualifizierten Listen wieder korrekt in einzelne Einträge getrennt.
- =FIXED= Wiktionary verarbeitet Bedeutungen, Beispiele, Herkunft, Synonyme und Redewendungen nun robuster auch aus list-basiertem HTML ohne =dl/dd=-Wrapper.
- =CHANGED= Fixture-based backend tests are now grouped by source and word in Buttercup output.
- =CHANGED= Changed headers to mimick Tor browser for better privacy.
- =CHANGED= Using if-let* and when-let* to be future proof.
- =CHANGED= Moved .el file into a lisp directory. Else using the package with use-package and ~:vc~ leads to compile errors as there is no ~:files~, only ~:lisp-dir~.
- =REMOVED= Removed elint from linters, always gave an error. But this makes it possible to add other Emacs versions for testing. This was removed, should be added in other projects:
  #+BEGIN_SRC makefile
  @printf '\e[1;34m%-10s\e[0m\n\n' '>>> elint'
  @$(EASK) lint elint --verbose 0
  #+END_SRC
